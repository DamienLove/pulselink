Deep Links

Open actions directly using pulselink:// URIs

Home Safety Beacon Deep Links Store iOS QA / Beta

PulseLink registers an app URI scheme pulselink:// for quick actions. These links open on a device with the app installed.

Note: Clicking on desktop browsers will not work. Test on an Android device with PulseLink installed.

Feature toggles

ActionLinkNotes
Emergencypulselink://assistant/emergencyStart emergency flow
Cancelpulselink://assistant/cancelCancel an active emergency (may require PIN)
Check‑inpulselink://assistant/checkinSend a quick check‑in to trusted contacts

Messaging intents

ActionTemplateExample
Standard message pulselink://assistant/message?contact={name}&text={text} pulselink://assistant/message?contact=Alex&text=Running%20late
Urgent message pulselink://assistant/urgent?contact={name}&text={text} pulselink://assistant/urgent?contact=Mom&text=Please%20call%20me
Non‑urgent w/ volume pulselink://assistant/nonurgent?contact={name}&text={text}&volume={level} pulselink://assistant/nonurgent?contact=Team&text=Meeting%20moved&volume=3
Emergency call request pulselink://assistant/call?contact={name} pulselink://assistant/call?contact=Sarah
