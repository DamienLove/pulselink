What is PulseLink?

PulseLink is a 3‑part suite:

  • Core: shared engine, data models, and UI foundations.
  • PulseLink Safety: the personal safety app that listens for discreet trigger phrases and escalates alerts with location to trusted contacts.
  • PulseLink Beacon: a modern SMS/MMS experience with safety‑aware features. Favorites can break through Do Not Disturb with a specific tone; senders can use a keyphrase to trigger an audible alarm on a linked device.

Safety and Beacon interoperate: if a linked contact triggers an emergency in Safety, Beacon can sound the emergency siren too.

What’s New

  • FCM relay via Cloud Functions — user‑to‑user link requests, approvals, and messages now deliver over Wi‑Fi using Firebase Cloud Messaging (no SMS required).
  • WebRTC signaling (beta) — experimental P2P DataChannel for low‑latency sessions; uses STUN, falls back to relay. Disabled by default unless both sides opt‑in.
  • Diagnostics Logger — export/share lightweight logs to help debug delivery and permissions issues.
  • Home screen widget — quick Emergency, Cancel, and Check‑in actions.
  • Improved trusted contact linking: clearer requests/approvals and resiliency on flaky networks.
  • Emergency alert routing with map deeplink and battery‑friendly background handling.
  • Assistant shortcuts and deep links for hands‑free actions.
  • Beacon DND bypass tones for favorites and emergency siren escalation.
