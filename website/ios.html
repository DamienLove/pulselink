PulseLink for iOS will bring discreet trigger and escalation to Apple devices. Initial focus is a reliable alert pipeline, privacy, and accessibility.

Goals

  • SwiftUI‑first UX with VoiceOver‑friendly flows
  • On‑device phrase detection for discreet triggers
  • Alert escalation to trusted contacts with location (consent‑driven)
  • Do Not Disturb‑aware notifications (critical alerts where approved)
  • Shared business logic via Kotlin Multiplatform where practical

Milestones

  1. MVP (private TestFlight): manual trigger → alert dispatch to a test contact; basic settings; analytics/crash with privacy.
  2. Beta (public TestFlight): phrase detection prototype, read‑only trusted contacts, critical alerts, SOS silent mode.
  3. GA 1.0 (App Store): production phrase detection, contact write flows, background resiliency, App Store privacy labels.

Build & Run (dev)

# From repository root
./gradlew :shared:podspec
cd iosApp
pod install
open PulseLinkiOS.xcworkspace
# Set signing team in Xcode, run the PulseLinkiOS scheme
