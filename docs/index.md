# PulseLink Suite

PulseLink is a 3‑part suite designed to keep people reachable when it matters most:

- Core: shared engine, models, and UI foundations used by all apps.
- PulseLink Safety: the emergency‑focused app that listens for discreet trigger phrases and escalates alerts (with location) to trusted contacts.
- PulseLink Beacon: a default SMS/MMS experience with safety‑aware features like favorites that can break through Do Not Disturb and keyphrase‑triggered alarms.
