# PulseLink Beacon

PulseLink Beacon is a safety‑aware default SMS/MMS experience. It helps you hear the right messages at the right time — even through Do Not Disturb — without requiring both people to install an app.

Highlights

- Favorites can break through DND with a distinct tone.
- Keyphrase alarm: if a message contains your private keyphrase, Beacon will play an audible alarm.
- Interoperates with PulseLink Safety: when a linked contact triggers an emergency in Safety, Beacon can sound the same siren.
- Designed for one‑sided activation: senders don’t need Beacon installed for the receiver to benefit.
- Roadmap (Beacon Pro): optional AI summarization of long threads and contextual DND bypass when messages indicate emergent risk.
