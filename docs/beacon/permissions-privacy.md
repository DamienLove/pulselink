# Permissions & Privacy

Why Beacon needs access

- Notifications/SMS: detect messages from favorites and keyphrase matches.
- Do Not Disturb access: allow urgent alerts to break through when you’ve enabled it.
- Storage/media (optional): select custom tones for emergencies.

Data handling

- Detection happens on‑device. Keyphrase matching does not leave your phone.
- No contact or message content is uploaded for these features.
- You can disable any permission at any time; affected features will pause gracefully.

Android notes

- Android 15+: verify the “Emergency Alerts” channel can bypass DND in system settings.
- Some OEMs add power optimizations. If alerts are delayed, exempt Beacon from battery optimizations.
