To enable Spotify streaming, download the Spotify App Remote SDK.

1. Download the zip from: https://github.com/spotify/android-sdk/releases
2. Extract it.
3. Locate the `spotify-app-remote-release-x.x.x.aar` file.
4. Rename it to `spotify-app-remote-release-0.8.0.aar` (or update the build.gradle version).
5. Place it in this folder.
